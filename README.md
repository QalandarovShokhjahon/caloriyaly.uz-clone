# 🥗 Caloriyaly Clone – Healthy Food Online Store

Bu loyiha Caloriyaly.uz ilhomida yaratilgan sog‘lom ovqatlar online do‘koni.
The project is a front-end clone created for learning and improving development skills.

---

## 🎯 Maqsad / Purpose

- Web frontend bo‘yicha o‘z **bilim va tajribamni oshirish**  
- Real loyihaga o‘xshash responsive website yaratish  
- HTML, CSS va JavaScript bilan amaliyot qilish

 ---

## 🚀 Tech Stack

- **HTML5**  
- **CSS3**  
- **JavaScript**  
- Fully responsive design

---

## 🌟 Features / Xususiyatlar

- 📦 Meal categories (Ovqatlar toifasi)  
- 🧮 Calories & nutritional info (Kaloriya ma’lumoti)  
- 💳 Add to cart UI (Frontend simulation)  
- 📱 Fully responsive – works on mobile, tablet, and desktop
